# 总体计划

## 项目目标

面向已接触过 Rust、希望系统学习机器学习系统的读者，沿 OpenMLSys 的
问题清单组织九章：编程接口、加速器、编译器、数据、训练、服务、强化学习
与 GPU 集群。Burn / CubeCL / CubeK 是贯穿案例，用来指出行为落在哪一层；
当代训练并行、推理服务与集群调度用可迁移的成本模型讲解，不把某一框架
的 API 写成系统边界。

## 原则

1. 先讲可迁移的系统原理，再进入实现落点。
2. 正文面向学习者：问题、成本、产业中的对应物、打开源码时该看哪个 crate。
   版本账本、证据标签和发布门禁留在附录与工具链（D025）。
3. 默认示例在 CPU 上可运行，便于没有加速器的读者动手；GPU 等作为递进实验。
4. 版本升级按写作周期集中进行，不让上游 `main` 驱动教材叙事。
5. OpenMLSys 内容逐节审查、重组和署名，不做字符串级语言替换。
6. 第 8 章为可选轨；基础设施主干是第 1–7 章与第 9 章。

## 里程碑

### M0：可持续写作基建

- mdBook 九章骨架可以构建。
- Rust 示例工作区有一个 CPU 冒烟示例。
- 上游版本、许可证和 Agent 边界可自动检查。
- CI 覆盖文档构建、格式、测试与 pin 校验。

### M1：最小纵向切片

- 完成第 2 章的张量、Backend 抽象和自动微分核心内容。
- 示例从正文可追踪，测试覆盖预期数值与形状。
- 建立一套经验证的章节写作模板。

### M2：基础篇

- 完成第 1–3 章。
- 形成从 Rust API 到 CubeCL Kernel 的学习闭环。
- 在至少两种本地可用后端上验证关键示例。

### M3：系统篇

- 完成第 4–6 章。
- 覆盖 IR、融合、数据管道、训练循环和可诚实验证的分布式能力。
- 对 Burn 尚未覆盖的领域使用框架无关叙事并明确边界。

### M4：应用与扩展篇

- 完成第 7–9 章。
- 覆盖 burn-onnx、远程推理、强化学习系统和 GPU 集群基础设施。
- 部署与集群章节包含可复现实验或最小模拟。

### M5：首个稳定版

- 全书术语、链接、引用、许可证和来源审计通过。
- 全部基础示例在固定快照上通过 CI。
- 发布带版本号的静态站点和离线构建说明。

## 章节完成定义

- 学习目标、先修知识和关键术语明确。
- 原理叙述不依赖单一框架。
- Burn/CubeCL/CubeK 源码定位基于 `pins.toml`。
- 至少一个可运行示例或明确说明为何不适合代码实验。
- 包含练习、延伸阅读、来源与改编说明。
- `make check` 通过，且状态文档已更新。
