# 2026-08-13 教科书化第一批（D023）

## 背景与决策

对照 OpenMLSys v1 完成态做读者视角分析后，确认四个最伤教材体验的
问题：全书零论文出处（原作 326 条 bib）、练习提示套话化（同句最多
复用 13 次/章）、审计腔密度（每千汉字 3 次「边界」、「固定」322 次）、
图文比过低（19 对 232 处图片引用）。据此新增 D023，在不放松证据纪律
的前提下修复表达层。原作 v2 重构确认为 TODO 骨架，本书九章即其规划的
独立实现，对照基准仍为 v1。

## 操作

1. **参考文献**：新增 `book/src/references.md`（教材与总览 + 九章
   分组，约 45 条，每条一句导读；链接只用有把握的 arXiv/DOI/官方站，
   无把握的条目只给出处不给 URL）。SUMMARY 附录挂载；九章练习页
   「延伸阅读」各加一行指针；README、ch01/05 与 ch07/05 的 LLM 边界
   段补 Orca/PagedAttention 出口。
2. **练习提示**：九章约 220 条折叠提示全部题目专属化（指向具体小节
   链接/示例观察点/源码路径 + 一句实质方向）。ch06 由本会话直接改写
   并修正两处错位提示；其余八章由八个并行子任务按统一质量标准改写，
   每个子任务自跑 `check_release` 与套话残留检查。
3. **审计腔消减**：ch05/05、ch06/06、ch07/01,02,05,06,07、ch08/04,05
   手工合并重复免责；全书正文（练习页除外）脚本化收敛「固定 X」
   修饰语（322→193 次），并修复脚本造成的 10 处中英粘连与 1 处
   「非固定」误伤；三个小节标题去「固定」（引用已同步）。ch08/06
   五连否改写为「系统需要 / 已提供 / 应用要补」分工表。
4. **配图**：新增 5 张 SVG 替换关键 ASCII 框图——`ch02-ml-workflow`
   （训练循环）、`ch04-lifetime-sync`（融合 vs 中途 sync 生命周期
   对比）、`ch05-worker-pipeline`（多 worker 数据通路）、
   `ch06-ddp-layers`（DDP 六层分工）、`ch08-actor-learner`
   （Actor–Learner 环）。Python UTF-8 写盘、读回比对、XML 解析，
   qlmanage 渲染目视核验并修正三处标签压线/溢出。
5. **体例**：AUTHORING 补「提示题目专属」「边界表述收敛」「参考
   文献页」「结构图优先 SVG」四条；DECISIONS 追加 D023（置于文件
   末尾保持升序）；九份 chapter-sources 各追加本批记录。

## 边界与偏差

- 「边界」词频从 280 升至约 306：增量来自新提示中对小节标题（如
  「集合通信、DDP 与能力边界」）的导航性链接，非新增免责句；正文
  免责句密度实际下降。SUMMARY 级小节标题未改名，避免破坏导航。
- 外链未做在线可达性验证（check_release 不校验外链）；无把握的
  文献条目已按 D023 只给出处。
- 本批为表达层修订；真实 GPU 实测、扩展篇缺章、LLM 专章等结构性
  缺口不在本批范围。
