## 验证

本机（Intel macOS / `x86_64-apple-darwin`）通过：

```text
cargo test -p ch01-stack-probe -p ch02-tensor-basics -p ch03-tile-loads
cargo clippy -p ch01-stack-probe -p ch02-tensor-basics -p ch03-tile-loads --all-targets -- -D warnings
mdbook build book
python3 tools/check_upstreams.py
cargo fmt --all --check
```

未能在本机完整运行（上游资产缺口，非本次正文错误）：

```text
cargo test -p ch03-cubecl-kernel
cargo test -p ch04-fusion-inspector
make check   # workspace 含上述两包
```

原因：`tracel-llvm` `v22.1.4-5` 发布资产含 `macos-AArch64`、`linux-x64`
等，但不含 `macos-x64`；CubeCL CPU / Burn `Device::cpu()` Fusion 依赖该
bundler 下载。Linux CI 与 Apple Silicon 路径不受此限制。`inspect_add_mul_exp`
已对照固定 Burn `burn-fusion` matchers（含 `is_mul_float`）静态核验。
