机器学习系统如何把模型定义转换为跨设备执行、训练和部署的程序？统一的
Rust 技术栈能帮助我们观察哪些传统框架隐藏的边界？

- Rust 对可移植性、安全性和部署形态的影响
- 如何阅读本书中的源码快照
