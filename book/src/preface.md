# 前言

许多机器学习系统教材同时跨越 Python、C++、CUDA、编译器框架和部署
工具。跨语言边界本身是真实系统的重要组成部分，但也会让初学者难以判断
一个抽象究竟在哪一层实现。

本书尝试另一条路径：以 Rust 和 Burn 生态为主线，从高层张量 API 一直
追踪到编译器中间表示、设备 Kernel 和运行时。统一技术栈使读者能够更
自然地研究类型、内存、并发和设备抽象，也能在需要时进入底层源码。

这不意味着排斥 Python、C++ 或 CUDA。它们仍会在历史背景、跨系统比较、
模型交换和硬件接口中出现，但不再承担串联全书实验的职责。

本书假定读者掌握 Rust 基础语法，了解基本机器学习概念；不要求已有 GPU
编程经验。基础实验优先提供 CPU 路径。
