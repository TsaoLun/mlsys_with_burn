# 前言

机器学习系统课通常要同时跨越 Python 接口、C++ 运行时、CUDA 内核、
编译器框架和部署工具。这些边界在真实系统里确实存在，但初学者往往还没
问清「这一层在解决什么问题」，就被换语言打断。

本书沿 OpenMLSys 的问题清单往下走，并用 Burn、CubeCL、CubeK 作为同一条
实现路径上的案例：从张量接口到 Kernel，从数据管道到训练循环，再从模型
产物到请求服务和集群调度。Python、C++、CUDA 仍会出现在历史背景和跨系统
比较里，只是不再承担串联全书实验的职责。

读完后，你应能用系统的语言描述一次训练或一次推理请求经过哪些层，并在
需要时打开对应的 crate，而不是只记住一组 API 名字。

本书假定读者掌握 Rust 基础语法，了解基本机器学习概念；不要求已有 GPU
编程经验。各章实验提供可在普通机器上运行的路径，运行方式见
[如何运行本书示例](running-examples.md)。

建议先翻[从应用到集群](infra-map.md)看全书地图，再按第 1 章给出的阅读
路径选一条。正文中的关键术语可以在[术语表](glossary.md)回查；在线站点
的搜索框基于英文分词，对中文内容检索效果有限，建议使用侧边栏目录导航。
