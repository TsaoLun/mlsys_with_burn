# 机器学习系统：基于 Burn 与 Rust 的设计和实现

本书面向已经接触过 Rust、希望把「能训练一个模型」推进到「能看懂训练、
推理和集群是怎样拼起来的」的读者。章节问题沿 OpenMLSys 的系统课组织：
编程接口、加速器、编译器、数据管道、训练、服务、强化学习与 GPU 集群。

实现案例走一条连续的技术路径，便于你打开同一组源码、顺着一次调用往下走：

```text
模型与训练
    Burn
张量、自动微分、图与融合
    Burn Core / Burn IR
设备无关 Kernel 与编译
    CubeCL
高性能算子
    CubeK
CPU、GPU、Web 与嵌入式运行时
```

Burn 不是机器学习系统的全部。数据并行之外的切分策略、请求服务、作业
调度等，仍从系统原理和成本模型讲起；需要对照产业里的名字时，见
[从应用到集群](infra-map.md)。想知道改一个算子会碰到哪些 crate，见
[一次调用会经过哪些层](crate-map.md)。

示例默认在普通 CPU 上即可运行。有 GPU 或其它环境时，各章会指出可以继续
往下做的部分。运行方式见[如何运行本书示例](running-examples.md)，术语见
[术语表](glossary.md)，论文与教材出处见[参考文献](references.md)。
来源与改编说明见[来源与改编总录](appendix-sources.md)。公式由 MathJax
渲染，浏览器阅读时需要访问相应的 CDN 资源。
