# 第 6 章 训练系统

## 本章问题

一个训练系统如何组织前向、反向、优化、检查点和跨设备通信，并在故障与
规模增长时保持效率？

## 计划内容

- 自定义训练循环与 burn-train
- 优化器、指标、日志和检查点
- 单机多设备执行
- 数据、模型、张量与流水线并行
- 集合通信与参数同步
- 容错、确定性和训练状态

## 实验

先实现可测试的单机训练循环，再依据固定版本能力扩展到多设备。

## 来源与改编说明

计划参考 OpenMLSys v1 `chapter_distributed_training/`。并行原理可以
保留，具体 API 必须按 Burn 当前实现核验；尚未实现的能力不会包装为
Burn 功能。
