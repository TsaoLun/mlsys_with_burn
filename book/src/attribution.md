# 许可、来源与独立性声明

本书改编自 OpenMLSys Team 的《机器学习系统：设计和实现》，原项目地址
为 <https://github.com/openmlsys/openmlsys>，采用 CC BY-NC-SA 4.0。
本书正文同样采用 CC BY-NC-SA 4.0。

改编工作包括按系统问题重组章节、以 Burn / Rust 实现替换原作中的框架
专用示例，并补上编译器、加速器、训练并行、推理服务和集群调度等当代
内容。各章文件级说明见[来源与改编总录](appendix-sources.md)。

本书使用 Burn、CubeCL、CubeK 和 burn-onnx 作为实现案例，但不是
OpenMLSys 或 Tracel 的官方项目，与二者均无隶属关系。

示例与正文对齐的依赖版本见[如何运行本书示例](running-examples.md)。
完整许可边界见仓库根目录的 `LICENSE.md` 与 `NOTICE.md`。
